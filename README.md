# Méridien — téléchargements

Atlas du monde, drapeaux, extensions Internet et entraînement géographique, en français.

[Télécharger la dernière version pour Windows 64 bits](https://github.com/Quentin-Red-Turtle/qrt-pkg-4e8c91/releases/latest)

Ouvrir l'installateur, puis le raccourci Méridien. Pour les prochaines versions : **Vérifier les mises à jour → Installer et relancer** dans l'application. Aucun compte GitHub ni Git n'est nécessaire. La progression est conservée.

Les anciennes copies 0.1 nécessitent cette première installation manuelle. Carte et exercices disponibles hors connexion ; Internet est nécessaire uniquement pour les mises à jour. Ce dépôt distribue les installateurs signés ; les sources sont conservées séparément.
